# Tutorial Demo (가제)

2D 픽셀아트 탑다운 액션 슈팅 데모. 동아리 부스 시연·스피드런용 튜토리얼 구간.
전체 설계는 [CLAUDE.md](CLAUDE.md) 참고.

> 진행: **M1~M10 완료** — PC 플레이 테스트·밸런스 조정 단계

## 실행 방법

1. [Godot 4.7.x](https://godotengine.org/download) 표준판(.NET 아님)을 받는다.
2. 이 저장소를 받는다: `git clone <저장소 주소>`
3. Godot 프로젝트 매니저 → **가져오기** → 저장소 폴더의 `project.godot` 선택.
   처음 열 때 이미지 가져오기(import)가 자동으로 진행된다.
4. **F5**(프로젝트 실행)로 실행.

## 조작

| 입력 | 동작 |
|---|---|
| WASD | 이동 |
| 마우스 | 조준 |
| 좌클릭 (누르고 있으면 연사) | 사격. 탄약이 0이면 못 쏨, 자동 재장전 없음 |
| 우클릭 | 근접 공격 = 패링. 적을 맞히거나 적 탄을 튕겨내면 탄약 회복 |
| Space | 회피 (이동 입력이 없으면 조준 방향) |
| Q | 스킬 (오른쪽 아래 아이콘, 쿨타임 중엔 어둡게) |
| Tab | 스킬 설정 — **출발(첫 조작) 전에만**. A/D·1~5 고르기, Tab·Enter 확정, Esc 취소 |
| R (0.5초 누르기) | 즉시 처음부터 재시작 |
| Esc | 일시정지 / 재개 |
| F11 | 전체화면 전환 |

- 근접을 누른 직후 짧은 순간에 적 탄을 튕기면 **완벽 패링** (크고 강한 관통 반사탄)
- 적 탄에 맞기 직전에 회피하면 **완벽 회피** → 잠깐 투명

- 체력 5칸 (왼쪽 위 하트). 맞으면 잠깐 무적. 0이 되면 쓰러지고 곧바로 처음부터 재시작
- E: 상호작용 · 컷씬 건너뛰기(두 번째 시청부터)

### 스킬 5종

시작 화면 없이 기본 스킬(충격파)로 시작한다. 바꾸려면 출발 전에 Tab. 고른 스킬은 재시작해도 유지된다.

| 스킬 | 효과 |
|---|---|
| 블링크 | 이동 방향으로 짧게 순간이동 (탄·구덩이 통과, 벽은 못 넘음) |
| 흡수 장막 | 2초간 앞의 적 탄을 탄약으로 바꿈 |
| 미끼 분신 | 분신을 남겨 적이 분신을 노리게 함 |
| 충격파 (추천) | 주변 적 탄 소거 + 적 밀쳐내기 |
| 표식 | 조준점 근처 적에게 표식, 받는 데미지 증가 |

### 튜토리얼 (타이틀에서 아무 키나 누르면 시작)

왼쪽에서 오른쪽으로 7구간이 이어진 고정 맵. 각 구간 입구가 스플릿 지점이다.
화면 하단에 작은 안내 문구가 나오고, 해 보면 저절로 사라진다 (게임은 멈추지 않음).

| 구간 | 내용 | 다음으로 가는 조건 |
|---|---|---|
| 1 이동·회피 | 엇갈려 오르내리는 가시 두 줄, 위에서 굴러오는 바위 | 없음 |
| 2 사격 | 약한 돌진형 4마리 | 적 전멸 → 문 열림 |
| 3 근접 | 들어오면 탄약 0. 돌진형 3마리를 베며 탄약 회복 | 적 전멸 |
| 4 패링 | 구덩이 너머 수정 스위치 + 원거리형 2마리 | 반사탄으로 수정을 맞히면 열림 (적은 남아도 됨) |
| 5 완벽 회피 | 탄막형 2마리 | 적 전멸 |
| 6 스킬 | 구덩이 띠(아래쪽으로 돌아가야 함) + 적 3종. 스킬마다 이득 (블링크 = 구덩이 지름길 등) | 적 전멸 |
| 7 미니 보스 | 탄막 골렘 (아래 참고) | 1페이즈 격파 → 타이머 정지 → 컷씬 |

- 구덩이: 걸어서는 못 건너지만 탄은 위로 지나간다
- 테스트 방으로 시작하려면 `data/game_config.tres`의 `use_tutorial = false`

### 탄막 골렘 (7구간)

- 7구간에 들어오면 깨어난다. 위쪽에 체력바
- 패턴 3종(원형 연발 / 조준 부채꼴 / 나선)을 고정 시드 순서로 반복 → 매 판 같은 순서
- 몸통은 일반 탄·근접에 거의 안 맞는다 (5번에 1). **튕겨낸 탄(반사탄)은 코어에 제대로 들어간다**
- 완벽 패링 반사탄을 연달아 맞히면 그로기 (별이 돌고 체력바가 노랗게 깜빡임) → 모든 공격이 3배
- 격파하면 타이머가 멈추고 2페이즈 시작 컷씬: 각성 → 필살기 → 주인공 쓰러짐 → 암전 → TO BE CONTINUED
- 컷씬은 첫 회는 끝까지, 두 번째부터 **E** 로 건너뛰기 (시청 기록은 `user://save.json`)
- 컷씬이 끝나면 기록 화면으로

### 스피드런

- 타이머(오른쪽 위): 첫 조작 입력에 시작, 골렘 1페이즈 격파에 정지. 게임 틱 기준이라 프레임 드랍 영향 없음
- 구간에 들어갈 때마다 스플릿과 1위 기록 대비 차이 (빠르면 초록, 느리면 빨강)
- 기록 화면: 총 기록·구간별 기록·스킬·순위. 상위 10위 안이면 이니셜 3글자 입력
  (글자 키로 바로 입력, 또는 W/S 글자 바꾸기 · A/D 칸 이동 · Backspace · Enter 등록) → Enter 로 다시 하기
- 기록 화면에서 Esc 또는 1분 동안 입력이 없으면 타이틀로
- 1위가 되면 그 판의 입력 기록(리플레이)을 저장 → 타이틀에서 30초 동안 가만히 있으면 자동 재생 (어트랙트 모드, 아무 키나 누르면 타이틀)
- 리더보드는 `user://leaderboard.json` (Windows: `%APPDATA%\Godot\app_userdata\<프로젝트 이름>\`)

### 테스트 방 (`use_tutorial = false` 일 때)

- 허수아비 3개: 사격·근접 연습 (맞으면 반짝임, 죽지 않음)
- 포탑 2개: 가까이 가면 느린 탄을 쏨 → 패링·완벽 회피 연습. 투명이면 마지막으로 본 위치에 쏜다
- 적 (투명한 플레이어는 못 보고 마지막으로 본 위치로 간다)
  - 돌진형(멧돼지): 다가오다 웅크린 뒤 일직선 돌진. 옆으로 피하거나 회피로 흘리기
  - 원거리형(보라 로브): 거리를 두고 느린 탄 → 패링으로 되받아치기
  - 탄막형(초록 가시눈): 사방으로 나선 탄막 → 완벽 회피·투명 체험

### 디버그 키 (에디터 실행·디버그 빌드에서만)

| 키 | 동작 |
|---|---|
| F1 | 히트박스 표시 (하늘색 몸통 / 초록 피격 / 빨강 공격) |

## 부스 관리 (관리자 키)

**Ctrl+Shift+F12** → 관리자 메뉴 (게임 안에는 안내 없음)

| 키 | 동작 |
|---|---|
| B | 리더보드·1위 리플레이를 날짜 붙은 파일로 백업 (같은 `user://` 폴더) |
| C 두 번 | 리더보드·1위 리플레이 초기화 |
| Esc | 닫기 |

## 소리

`data/audio.tres` 의 슬롯(사격·근접·패링·완벽 판정·피격·보스)에 `art/audio/` 의 파일 경로를 넣으면 울린다. 비어 있으면 무음.

## 수치 바꾸기

모든 수치는 `data/*.tres`에 있다. 에디터 파일 시스템에서 더블클릭해 인스펙터로 고치거나, 텍스트로 직접 고쳐도 된다.

| 파일 | 내용 |
|---|---|
| `data/game_config.tres` | 틱 수, 데모 모드, 시드, 시작 맵, 재시작 홀드 시간, 사망 후 재시작 대기, 리더보드 인원, 어트랙트·기록 화면 대기 시간 |
| `data/player.tres` | 이동 속도, 충돌·피격 크기, 체력, 피격 후 무적 |
| `data/dodge.tres` | 회피 속도·지속·무적·쿨타임 (틱 단위, 60틱 = 1초) |
| `data/gun.tres` | 탄창 크기, 시작 탄약, 연사 간격 |
| `data/melee.tres` | 근접 판정 시간·후딜·범위·데미지, 명중 시 탄약 회복량 |
| `data/parry.tres` | 패링 탄약 회복량, 반사탄 속도·데미지, 완벽 패링 판정창·강화 배율 |
| `data/stealth.tres` | 완벽 회피 판정창·스침 여유 거리, 투명 지속 시간 |
| `data/projectiles/*.tres` | 탄 종류별 속도·데미지·크기·수명 |
| `data/props/*.tres` | 테스트 방 허수아비·포탑 |
| `data/enemies/*.tres` | 적 종류별 체력·속도·시야·공격 패턴 수치 (`charger_weak` = 2구간용 약한 돌진형) |
| `data/tutorial.tres` | 구간별 맵 파일, 안내 문구, 문구가 사라지는 조건, 탄약 0 여부, 문 열림 조건, 표지판 글, 출발 전 안내 |
| `data/skills/*.tres` | 스킬별 이름·설명·쿨타임·효과 수치 (`game_config.tres`의 `default_skill_id` = 처음 스킬) |
| `data/hazards/*.tres` | 가시 주기·데미지, 바위 간격·속도 |
| `data/bosses/golem.tres` | 골렘 체력, 몸통·코어 피해 규칙, 그로기 조건, 패턴 3종 수치, 컷씬 단계별 길이 |
| `data/feel.tres` | 화면 흔들림·번쩍임 세기, 회피 잔상 (화면 연출만, 기록과 무관) |
| `data/audio.tres` | 효과음 파일 경로·볼륨 |
| `data/theme.tres` | 아트 테마 폴더 |

## 튜토리얼 맵 고치기

`levels/tutorial/sections/section_1.txt` ~ `section_7.txt` 를 텍스트 편집기로 고친다.
파일 위쪽 `;` 주석에 글자 뜻이 적혀 있다. 모든 구간은 높이 13줄, 마지막 열이 오른쪽 벽(5~7행 = 출구).

## 스프라이트 다시 만들기

```
pip install pillow
python3 tools/sprite_gen.py
```

`art/themes/dungeon/`에 PNG·JSON이 다시 생성된다 (같은 코드면 항상 같은 결과).
팔레트는 `palette.gpl`(Aseprite·GIMP에서 불러오기 가능).

## 자동 테스트 (헤드리스)

```
godot --headless --path . --import
godot --headless --path . --fixed-fps 60 res://tests/test_runner.tscn
```

스크립트로 입력을 흘려 넣어 이동·회피·충돌·결정론을 검사한다. 실패가 있으면 종료 코드 1.

## Windows exe 빌드

내보내기 설정(`export_presets.cfg`, "Windows Desktop")은 이미 들어 있다.
스프라이트 정보(`*.json`)·맵(`*.txt`)을 포함하고, 테스트 폴더는 빼고, exe 하나에 데이터까지 넣도록 되어 있다.

1. Godot 에디터 → **에디터 → 내보내기 템플릿 관리** → **다운로드 및 설치** (처음 한 번, 4.7.x 버전용)
2. **프로젝트 → 내보내기** → "Windows Desktop" 선택 → **프로젝트 내보내기**
   - **디버그와 함께 내보내기** 체크를 **끈다** (부스용: 디버그 키 F1~F4 가 꺼진다)
   - 저장 위치 기본값: `export/TutorialDemo.exe`
3. 만들어진 exe 하나만 부스 PC로 복사해 실행. 전체화면은 F11 (또는 `data/game_config.tres` 의 `start_fullscreen = true`)

명령줄로는:

```
godot --headless --path . --export-release "Windows Desktop" export/TutorialDemo.exe
```

※ exe 아이콘을 바꾸려면 Windows 에서 내보내거나 rcedit 설정이 필요하다 (Godot 문서 "Changing application icon for Windows").
