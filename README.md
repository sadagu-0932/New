# Tutorial Demo (가제)

2D 픽셀아트 탑다운 액션 슈팅 데모. 동아리 부스 시연·스피드런용 튜토리얼 구간.
전체 설계는 [CLAUDE.md](CLAUDE.md) 참고.

> 현재 진행: **M3** (적 3종, 체력·피격·사망·재시작)

## 실행 방법

1. [Godot 4.7.x](https://godotengine.org/download) 표준판(.NET 아님)을 받는다.
2. 이 저장소를 받는다: `git clone <저장소 주소>`
3. Godot 프로젝트 매니저 → **가져오기** → 저장소 폴더의 `project.godot` 선택.
   처음 열 때 이미지 가져오기(import)가 자동으로 진행된다.
4. **F5**(프로젝트 실행)로 실행.

## 조작 (현재 구현된 것)

| 입력 | 동작 |
|---|---|
| WASD | 이동 |
| 마우스 | 조준 |
| 좌클릭 (누르고 있으면 연사) | 사격. 탄약이 0이면 못 쏨, 자동 재장전 없음 |
| 우클릭 | 근접 공격 = 패링. 적을 맞히거나 적 탄을 튕겨내면 탄약 회복 |
| Space | 회피 (이동 입력이 없으면 조준 방향) |
| R (0.5초 누르기) | 즉시 처음부터 재시작 |
| Esc | 일시정지 / 재개 |

- 근접을 누른 직후 짧은 순간에 적 탄을 튕기면 **완벽 패링** (크고 강한 관통 반사탄)
- 적 탄에 맞기 직전에 회피하면 **완벽 회피** → 잠깐 투명

- 체력 5칸 (왼쪽 위 하트). 맞으면 잠깐 무적. 0이 되면 쓰러지고 곧바로 처음부터 재시작

스킬(Q)·상호작용(E)은 이후 마일스톤에서 추가된다.

### 테스트 방 (현재 시작 맵)

- 허수아비 3개: 사격·근접 연습 (맞으면 반짝임, 죽지 않음)
- 포탑 2개: 가까이 가면 느린 탄을 쏨 → 패링·완벽 회피 연습. 투명이면 마지막으로 본 위치에 쏜다
- 적 (투명한 플레이어는 못 보고 마지막으로 본 위치로 간다)
  - 돌진형(멧돼지): 다가오다 웅크린 뒤 일직선 돌진. 옆으로 피하거나 회피로 흘리기
  - 원거리형(보라 로브): 거리를 두고 느린 탄 → 패링으로 되받아치기
  - 탄막형(초록 가시눈): 사방으로 나선 탄막 → 완벽 회피·투명 체험

### 디버그 키 (에디터 실행·디버그 빌드에서만)

| 키 | 동작 |
|---|---|
| F1 | 히트박스 표시 (하늘색 몸통 / 초록 피격 / 빨강 공격) |
| F2 | 무적 |
| F3 / F4 | 이전 / 다음 구간 시작 지점으로 이동 |

## 수치 바꾸기

모든 수치는 `data/*.tres`에 있다. 에디터 파일 시스템에서 더블클릭해 인스펙터로 고치거나, 텍스트로 직접 고쳐도 된다.

| 파일 | 내용 |
|---|---|
| `data/game_config.tres` | 틱 수, 데모 모드, 시드, 시작 맵, 재시작 홀드 시간, 사망 후 재시작 대기 |
| `data/player.tres` | 이동 속도, 충돌·피격 크기, 체력, 피격 후 무적 |
| `data/dodge.tres` | 회피 속도·지속·무적·쿨타임 (틱 단위, 60틱 = 1초) |
| `data/gun.tres` | 탄창 크기, 시작 탄약, 연사 간격 |
| `data/melee.tres` | 근접 판정 시간·후딜·범위·데미지, 명중 시 탄약 회복량 |
| `data/parry.tres` | 패링 탄약 회복량, 반사탄 속도·데미지, 완벽 패링 판정창·강화 배율 |
| `data/stealth.tres` | 완벽 회피 판정창·스침 여유 거리, 투명 지속 시간 |
| `data/projectiles/*.tres` | 탄 종류별 속도·데미지·크기·수명 |
| `data/props/*.tres` | 테스트 방 허수아비·포탑 |
| `data/enemies/*.tres` | 적 종류별 체력·속도·시야·공격 패턴 수치 |
| `data/theme.tres` | 아트 테마 폴더 |

## 스프라이트 다시 만들기

```
pip install pillow
python3 tools/sprite_gen.py
```

`art/themes/dungeon/`에 PNG·JSON이 다시 생성된다 (같은 코드면 항상 같은 결과).
팔레트는 `palette.gpl`(Aseprite·GIMP에서 불러오기 가능).

## 자동 테스트 (헤드리스)

```
godot --headless --path . --import
godot --headless --path . --fixed-fps 60 res://tests/test_runner.tscn
```

스크립트로 입력을 흘려 넣어 이동·회피·충돌·결정론을 검사한다. 실패가 있으면 종료 코드 1.
